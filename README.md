# 🧱 Clay Imports – Shopify Theme Customization

This is the full exported theme for **Clay Imports**, a tile and design company. I worked as the lead developer on the Shopify storefront, implementing custom frontend logic, performance optimizations, and personalized customer experience components.

---

## 🔨 Highlights

✅ Optimized theme.liquid and JavaScript for performance (never ending task lol)
✅ Implemented dual layout switching (desktop/mobile)  
✅ Developed `<details>` scraping logic for product usage
✅ Cleaned and refactored Liquid structure (removed unnecessary sections that can be embedded into others)
✅ Integrated AI chatbot (ClayBot) to enrich support

---

## 📦 What's Included

This theme contains all templates, sections, snippets, and config files.  
The `/assets` folder was excluded to protect visual content and reduce repo size.

---
## 🤖 ClayBot Not Included

This repository does **not** include the code for **ClayBot**, the custom AI-powered chatbot I developed for Clay Imports.

ClayBot is still under active development as a separate project, and you can find the full codebase and ongoing work here:

👉 [Chatbot_ClayImports GitHub Repository](https://github.com/DiegoIniguez/Chatbot_ClayImports)

ClayBot integrates:
- OpenAI API for natural language responses
- Weekly learning and fine-tuning
- Semantic search and recommendation engine
- Shopify product matching and live scraping
